# Screenshots & GIF Upload Guide

This repo does **not** store binary assets. Instead, upload screenshots/GIFs to GitHub and paste the hosted URLs into `README.md`.

## Quick Steps (GitHub Issues)
1. Open a new issue in this repo.
2. Drag & drop your PNG/GIF files into the issue comment box.
3. GitHub will upload the files and generate URLs like:
   `https://user-images.githubusercontent.com/.../your-image.png`
4. Copy the URLs and replace the placeholders in `README.md`.

## Tips for Portfolio Quality
- **Hero/cover image:** 1280×640 or 1600×800.
- **Screenshots:** 1280×720 or higher.
- **GIF duration:** 8–15 seconds, 10–15 FPS.
- **Keep sizes light:** prefer <10MB per asset.

## Recommended Naming (for clarity in README)
- Hero banner
- Gameplay GIF
- Screenshot 1 (gameplay)
- Screenshot 2 (HUD/game-over)
- Screenshot 3 (settings/summary)
