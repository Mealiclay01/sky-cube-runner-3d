# Contributing

Thanks for your interest in improving **Sky Cube Runner 3D**!

## Quick Guidelines
- Keep changes lightweight and focused.
- Avoid adding heavy dependencies.
- Follow the existing Swift style and Xcode project structure.
- Update documentation if behavior or UI changes.

## How to Contribute
1. Fork the repo and create a feature branch.
2. Make your changes and test in Xcode.
3. Submit a pull request with a clear description.
